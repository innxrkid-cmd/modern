# Modern HRMS

A fullstack Human Resource Management System built with React, Tailwind CSS, React Router, Axios, Node.js, Express.js, MongoDB Atlas, and JWT authentication.

## Structure

- `frontend` - React + Vite + Tailwind CSS
- `backend` - Node.js + Express + MongoDB Atlas

## Getting Started

### Backend

1. Create a `.env` file from `.env.example`
2. Install dependencies:
   ```bash
   cd backend
   npm install
   ```
3. Start the backend:
   ```bash
   npm run dev
   ```

### Frontend

1. Install dependencies:
   ```bash
   cd frontend
   npm install
   ```
2. Start the frontend:
   ```bash
   npm run dev
   ```

## Deployment

- Frontend can be deployed to Vercel.
- Backend can be deployed to Render or another Node.js host.
